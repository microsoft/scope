{/* ============================ HOW IT WORKS ============================ */}
<section class="scope-section">
	<div class="scope-section__head">
		<span class="scope-section__eyebrow">How it works</span>
		<h2>One task, every agent, measured the same way</h2>
		<p>Scope submits your task to each agent, scores every run against the criteria you define, and lines the results up side by side.</p>
	</div>

	<div class="scope-steps">
		<div class="scope-step">
			<span class="scope-step__k">01</span>
			<h3>Submit a task</h3>
			<p>Hand one coding task to GitHub Copilot, Claude Code, or VS Code with the Copilot driver extension — with the profile you want.</p>
		</div>
		<div class="scope-step">
			<span class="scope-step__k">02</span>
			<h3>Score against criteria</h3>
			<p>Each run is evaluated against your criteria DAG. Gate child criteria on their parents, or leave them as independent roots.</p>
		</div>
		<div class="scope-step">
			<span class="scope-step__k">03</span>
			<h3>Compare trajectories</h3>
			<p>See not just whether it worked, but how each agent got there — the tools it reached for and where it got stuck.</p>
		</div>
	</div>
</section>

{/* ============================ FEATURES ============================ */}
<section class="scope-section">
	<div class="scope-section__head">
		<span class="scope-section__eyebrow">What you can do</span>
		<h2>Not “did it work?” — how did it get there?</h2>
		<p>Scope drives existing agents against tasks you control, then captures what they asked for, what tools they reached for, and where they got stuck.</p>
	</div>

	<div class="scope-features">
		<div class="scope-feature">
			<span class="scope-feature__no">01</span>
			<h3>Submit a coding task</h3>
			<p>Hand a task to GitHub Copilot, Claude Code, or VS Code with the Copilot driver extension.</p>
		</div>
		<div class="scope-feature">
			<span class="scope-feature__no">02</span>
			<h3>Save reusable profiles</h3>
			<p>Bundle worker, model, version, MCP servers, skills, and extensions to re-run a setup consistently.</p>
		</div>
		<div class="scope-feature">
			<span class="scope-feature__no">03</span>
			<h3>Define criteria as a DAG</h3>
			<p>Describe what “good” means. Gate child criteria on their parents, or leave them as independent roots.</p>
		</div>
		<div class="scope-feature">
			<span class="scope-feature__no">04</span>
			<h3>Watch runs live</h3>
			<p>Stream logs straight from the worker as each run executes, attempt by attempt.</p>
		</div>
		<div class="scope-feature">
			<span class="scope-feature__no">05</span>
			<h3>Slice with prompt features</h3>
			<p>Scope detects characteristics on your prompts so you can compare across heterogeneous tasks.</p>
		</div>
		<div class="scope-feature">
			<span class="scope-feature__no">06</span>
			<h3>Automate everything</h3>
			<p>Submit runs, manage profiles and criteria, and fetch results through the REST API or the CLI.</p>
		</div>
	</div>
</section>
