Scope is open source, and some issues are set aside for the community.
Each one below is open and nobody is assigned to it yet.

## How to pick one up

1. Choose an issue below. **Good first issue** marks a small, well-scoped
   change. **Help wanted** marks work where an outside hand helps most.
2. Read the
   [contributing guide](https://github.com/microsoft/scope/blob/main/CONTRIBUTING.md)
   to set up your environment and learn the conventions.
3. Open a pull request that references the issue, for example
   `Fixes #123`. You don't need to comment on the issue or ask first.

The first time you contribute, a bot asks you to sign the Microsoft
Contributor License Agreement (CLA). You only sign it once.
